# Dell'arte dello schermire

Reader-facing Italian-German HTML edition of Giovanni dall'Agocchie's first
book, *Dell'arte dello schermire* (Venice, 1572).

Open [`index.html`](index.html) to read the edition. The page starts in the
facing-page comparison view and lets readers choose German only, Italian only,
or the comparison. The selected view is remembered in the browser.

The public repository contains only the reader-facing HTML files. The source
corpus and editorial working files remain in the private working repository.
